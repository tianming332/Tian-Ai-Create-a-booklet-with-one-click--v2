# AutoBook · 一键成册

导入照片与文案，自动排版成册，导出可印刷的 PDF。全程在浏览器本地运行，文件不离开你的设备。

传统画册制作需要整理素材、判断叙事顺序，再在专业软件中逐页建立网格、处理跨页并检查印刷规范。AutoBook 把这些编辑设计规则交给系统执行：分析图片比例、视觉重心与图文关系，自动组织顺序并生成整本册子的初稿，把时间留给内容选择和最终的审美判断。

## 功能

- 导入照片与文案：支持批量导入图片和文字素材，自动读取照片信息。
- 选择版式：按内容选择版式方向与开本。
- 自动排版：规则排版与 AI 排版两种方式，图文混排，分钟级生成整本初稿。
- 预览与编辑：重新排序、替换图片、调整文字与版式。
- 审核导出：印刷预检后导出可分享或印刷的 PDF。
- 本地优先：无需专业排版软件，素材不上传到服务器。

## 运行

```bash
npm install
npm run dev      # 本地开发
npm run build    # 构建
npm test         # 测试
```
